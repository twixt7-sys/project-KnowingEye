Production Face Detector (MediaPipe BlazeFace) - Test-Split Evaluation

The face-presence stage of the deployed Knowing Eye pipeline uses MediaPipe Face Landmarker, whose detection stage is Google's pre-trained BlazeFace (short-range) model. Unlike the YOLOv8n, YOLOv11n and RT-DETR-l detectors, it was not trained or fine-tuned in this study, so it has no training or validation curves and uses neither the training nor the validation split. It was evaluated once, frozen, on the same held-out test split used for the fine-tuned detectors: 402 images containing 1,005 annotated faces.
The evaluation runs exactly the production code path: each image is resized to 640 px wide, denoised with a bilateral filter and histogram-equalised (prepare_frame_pair), then passed to FaceDetector.detect with the deployed settings (up to 3 faces, minimum detection confidence 0.62, plausibility filter). A detection counts as a true positive when it overlaps an annotated face with IoU ≥ 0.5. Accuracy = TP / (TP + FP + FN), the same definition used for the fine-tuned detectors.

6. Inference Speed

Measured on CPU only (Intel Core i5-11300H laptop, no GPU), over 399 test images after warm-up: 77.55 ms per image for detection (12.9 FPS) and 27.6 ms for preprocessing (9.5 FPS end to end). The production pipeline samples the webcam at 5 frames per second (target_fps: 5), so detection fits the frame budget without a GPU.

Conclusion

The production detector is highly precise: 1 false detection across all 402 test images (99.78% precision), so when it reports a face, a face is almost always there. Within its documented operating domain it finds 86.18% of faces (85.99% accuracy, 92.47% F1). Across all faces, recall falls to 45.07% because most WIDER FACE faces are small faces in crowds, which the model card lists as out of scope and which the fine-tuned detectors were trained on.
On examinee-sized faces scored with identical code, MediaPipe reached 85.99% accuracy and 92.47% F1 against 82.34% and 90.32% for YOLOv11n, the strongest fine-tuned detector. The two make opposite errors: YOLOv11n finds more faces (98.70% vs. 86.18% recall) but produces 92 false detections against MediaPipe's 1 (83.24% vs. 99.75% precision). MediaPipe also supplies the facial landmarks and head pose that the gaze and identity checks need, which a bounding-box detector alone does not, so it remains the deployed face detector.
Limitations: the test images are FDDB and WIDER FACE photographs, not webcam frames from examination sessions, so these results do not by themselves measure accuracy under exam conditions. Google's published figures (Section 1) come from Google's own smartphone and webcam data. A test on webcam recordings of consenting participants is needed to measure the deployed face-presence accuracy directly. The model card also lists surveillance as an out-of-scope use; the system therefore treats detections as behavioral indicators for administrator review, not as findings of misconduct.

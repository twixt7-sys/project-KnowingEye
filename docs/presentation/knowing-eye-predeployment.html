Introduction

Background and Problem Statement

PROBLEM · LCC ENVIRONMENTAL SCAN, JUNE 1, 2026
  • No computer-based exam system with face tracking or identity verification.
  • Suspicious behavior is caught only by CCTV or assigned proctors, which does not scale to large exams.
  • Existing platforms manage exams but monitor passively, with no real-time behavior analysis.

Proposed: one web platform for exam creation, administration, and real-time facial and postural behavior monitoring.

EBI = (Fp + Fi + Up + Gc) / N
FpFace presence
FiIdentity consistency
UpUpper-body presence
GcLooking-away compliance

Formative indicators. Raw frames are not stored; only derived metrics.

Good · EBI ≥ 80
Mid · 50–79 · review
Bad · < 50 · prioritize

Bands follow a graduated risk model and threshold-based classification.
